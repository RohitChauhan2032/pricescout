# PriceScout

PriceScout is a modern, responsive product comparison and deal discovery web application built with HTML5 and CSS3.

## 🚀 Features

- **Home / Discovery Page** (`index.html`): Hero search and curated product recommendations with Scout score badges.
- **Category Comparison Page** (`category.html`): Comprehensive smartphone comparison catalog with quick filter chips, detailed specs, pricing, and live deal links.
- **Product Details Page** (`product.html`): Individual product breakdown, specifications, price comparisons, and reviews.
- **Buying Guides** (`article.html`): Curated buying guides and editorial reviews.
- **Empty / No Results State** (`empty.html`): Clean fallback state for missing searches/deals.
- **Responsive Layout**: Designed for mobile, tablet, and desktop screens with micro-animations.

## 📁 Tech Stack

- **HTML5** (Semantic structure)
- **Vanilla CSS3** (Flexbox, Grid, Custom Keyframe Animations, Responsive Media Queries)
- **Google Fonts** (Inter)

## 💻 Getting Started

Simply open `index.html` in any web browser to view the application locally.
